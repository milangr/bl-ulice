# Banja Luka – zatvorene ulice

[Otvori mapu](https://milangr.github.io/bl-ulice/)

Interaktivna mapa planiranih obustava saobraćaja za **25.10.2026.**, zbog Banjalučkog maratona.

- Boje predstavljaju pet termina iz gradske obavijesti.
- Označene su glavne trase, bez bočnih ogranaka i prilaza.
- Prelazak mišem preko prikazane ulice pokazuje njen naziv.
- Krfska je prikazana na Istočnom tranzitu, paralelno sa Stevana Bulajića; OpenStreetMap taj dio naziva Bulevar Solunaca.
- Spoj Kralja Petra I Karađorđevića od Aleje Svetog Save do Olimpijskih pobjednika prikazan je posebno isprekidano: termin zatvaranja nije potvrđen.

Podaci predstavljaju plan obustave, a ne stanje saobraćaja uživo. Ostale isprekidane dionice imaju približne granice.

Izvori: [Grad Banja Luka](https://www.banjaluka.rs.ba/zbog-odrzavanja-manifestacije-banjal-2/) i [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
